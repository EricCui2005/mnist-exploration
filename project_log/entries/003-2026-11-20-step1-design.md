# 003: Step 1 design — rebuild the last layer from stored writes
Date: 2026-11-20   Follows: [002](002-2026-11-20-project-restart.md)

**What:** A new script, `step1_dual_form.py`, trains an MLP and stores the key and the error of each write to the last layer.
**Why:** All later attribution depends on an exact dual form. This step examines that property first.
**Decisions:**
- MLP 784-800-800-10 — the same model as Irie et al.
- Plain SGD, lr 0.1, batch 128, 1 epoch — the dual form is exact only under plain SGD.
- Last layer only — it is the smallest layer and the easiest to read.
- Weights only, not the bias — the bias does not change the question.

**Expected result:** A relative error near 1e-6 (float rounding). A larger error shows a defect in the logs or in the SGD setup.
