# 006: Step 2 result — attention finds the class, but also tracks key size
Date: 2026-11-20   Follows: [005](005-2026-11-20-step2-design.md)

**What:** The script ranked all training examples by attention for test image 0 (label 7).
**Result:** [step2_attention.png](../../figures/step2_attention.png)
- The top 100 examples are all 7s (100%).
- The top 8 are thick, bright 7s. The bottom 8 are thin 1s, one 6, and one 3.
- The correlation of attention with the key size `|k|` is 0.53.
- All attention scores are positive (minimum 18).

**Interpretation:**
- Attention finds the test class, as Irie et al. report.
- Attention also measures key size, so thick strokes rank high.
- The keys and the query come after a ReLU, so they are never negative. Attention can only show similarity. It cannot show that an example works against the prediction.
- One test image only; the result does not show faithfulness.
