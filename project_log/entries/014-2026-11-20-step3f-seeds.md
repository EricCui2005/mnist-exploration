# 014: Step 3f — the method order holds over 3 seeds; the query gap varies
Date: 2026-11-20   Follows: [013](013-2026-11-20-step3e-misclassified-test-image.md)

**What:** `step3_removal.py --random 20 --k 1000 --test 4433 --seed S` for S = 0, 1, 2.
**Why:** All earlier runs used seed 0, so the seed noise was unknown.
**Decisions:** The rankings stay from the seed 0 logs. Only the retrain seed changes (initial weights and batch order). Seeds 1 and 2 thus also test whether a ranking transfers to a different training run.

**Result:** loss change on test image 4433 (random: mean ± std of 20 draws).

| Removed top 1000 of | Seed 0 | Seed 1 | Seed 2 |
|---|---|---|---|
| Random | +0.01 ± 0.10 | +0.04 ± 0.09 | +0.04 ± 0.08 |
| Raw attention | +0.16 | +0.23 | +0.16 |
| Cosine attention | +2.27 | +1.97 | +1.36 |
| Error norm (7s, no query) | +2.87 | +3.62 | +3.37 |
| Attention × error | +4.14 | +4.79 | +3.63 |
| Gap: attention × error − error norm | +1.27 | +1.18 | +0.26 |

**Interpretation:** The order of the methods is the same for all 3 seeds. The query gap is positive for all 3 seeds, but it varies (mean +0.90). For seed 2, the gap is only 3 times the random spread. The rankings transfer to other training runs. One test image only.
