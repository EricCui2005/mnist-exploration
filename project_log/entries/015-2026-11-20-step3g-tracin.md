# 015: Step 3g — attention × error is equal to or better than last-layer TracIn
Date: 2026-11-20   Follows: [014](014-2026-11-20-step3f-seeds.md)

**What:** `step3_removal.py` adds a last-layer TracIn ranking: `sum eta (k_i^T q_t)(e_i^T e_q,t)`, with the test query and test error at the time of each write. Run on test image 4433, k = 1000, seeds 0, 1, 2.
**Why:** TracIn is the standard baseline. It has the same training side as attention × error; only the test side differs (the model at write time, not the final model).
**Decisions:**
- Last layer only, no bias term — the only difference from attention × error is the test side.
- The script replays the seed 0 run to get `q_t` and `e_q,t` before each write. No checkpoints are stored.

**Result:** TracIn and attention × error have a correlation of 0.89; their top-1000 sets share 795 examples.

| Removed top 1000 of | Seed 0 | Seed 1 | Seed 2 |
|---|---|---|---|
| Error norm (7s, no query) | +2.87 | +3.62 | +3.37 |
| TracIn (last layer) | +4.01 | +4.22 | +3.07 |
| Attention × error (last layer) | +4.14 | +4.79 | +3.63 |
| Random (mean of 20 draws) | +0.01 | +0.04 | +0.04 |

**Interpretation:** Attention × error is equal to or better than TracIn for all 3 seeds (mean difference +0.42). For seed 2, TracIn is below the error-norm control. The two scores are similar, but the final-model test side gives a slightly better ranking here. One test image only.
