# 011: Step 3c — removal test at k = 1000
Date: 2026-11-20   Follows: [010](010-2026-11-20-step3b-removal-noise.md)

**What:** `step3_removal.py --random 20 --k 1000` repeats step 3b with the top 1000 examples, and with 20 random sets of 1000.
**Why:** Eric asked whether a larger removal changes the result.
**Decisions:** Everything else is the same as step 3b (seed 0, test image 0, 20 random draws).

**Result:** random removal changes the test-0 loss by +0.00005 ± 0.00013 (range −0.00025 to +0.00022). The full retrain loss is 0.00132.

| Removed top 1000 of | Loss change | Ratio | z against random | Beats random draws |
|---|---|---|---|---|
| Raw attention | −0.00002 | 0.98x | −0.6 | 20% |
| Cosine attention | +0.00017 | 1.13x | +1.0 | 85% |
| Attention × error | +0.00094 | 1.71x | +7.1 | 100% |

**Interpretation:** The attention × error effect grows with k (+0.00035 at k = 100, +0.00094 at k = 1000). It stays far outside the random spread. Raw attention stays equal to random. Cosine is now inside the random spread. One seed and one test image only.
